# Обзор репозитория: My Form (Prestige HQ)

Этот репозиторий представляет собой легковесное веб-приложение для создания, прохождения и управления интерактивными тестами (квизами) и формами непосредственно в браузере. Проект написан на чистых технологиях (Vanilla JavaScript, HTML5 и CSS3) без использования тяжелых фреймворков.

---

## 🚀 Основные возможности

* **Динамические вкладки форм:** Поддержка создания и переключения между несколькими независимыми формами/тестами.
* **Разнообразные типы вопросов:**
* Одиночный выбор (`radio`)
* Множественный выбор (`checkbox`)
* Выпадающий список (`select`)
* Текстовый ввод с поддержкой синонимов (`text`)
* Продвинутые голосовые карточки (`voice_card`)


* **Панель администратора:** Защищенный паролем интерфейс для добавления новых вопросов, настройки таймеров, обязательных полей и блоков с объяснениями (подсказками/теорией) после ответа.
* **Импорт и экспорт:** Возможность выгружать созданные формы в формате `.JSON` файлов и загружать их обратно.
* **Система тем:** Встроенная поддержка светлой и темной тем оформления, автоматически подстраивающаяся под интерфейс.
* **Интерактивные элементы:** Встроенные таймеры для вопросов, шкала прогресса, детальный экран результатов с анализом ошибок и правильных ответов.

---

## 📂 Структура проекта

Хотя репозиторий компактен, его логика разделена на понятные модули:

* `index.html` — главная страница, содержащая разметку интерфейса пользователя, экрана авторизации, панели администратора и модальных элементов.
* `style.css` — таблица стилей с использованием CSS-переменных, обеспечивающая адаптивный дизайн и поддержку темной темы.
* `script.js` — ядро приложения, отвечающее за рендеринг вопросов, обработку пользовательского ввода, управление локальным хранилищем (`localStorage`) и переключение экранов.

---

## 🛠️ Технологический стек

* **Frontend:** HTML5, CSS3 (CSS Variables, Flexbox, Animations), JavaScript (ES6+).
* **Иконки:** Material Symbols Rounded.
* **Хранение данных:** Локальное хранилище браузера (`localStorage`) и работа с JSON-файлами.

---

## 📌 Заключение

Проект **My Form** — это отличный, самодостаточный инструмент для быстрого создания тестов или опросников без необходимости развертывания сложных бэкенд-серверов. Благодаря чистой архитектуре код легко модифицировать, дополнять новыми функциями и интегрировать в сторонние сайты.
