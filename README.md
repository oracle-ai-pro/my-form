# Обзор репозитория: Prestige HQ WorkSuite (My Work)

**Prestige HQ WorkSuite** (ранее *My Form*) — это лёгкая, быстрая и автономная веб-экосистема офисных и учебных инструментов, работающая прямо в браузере. Проект эволюционировал из одиночного конструктора тестов в полноценный хаб сервисов, написанный на чистых веб-технологиях (Vanilla JavaScript, HTML5, CSS3) без громоздких фреймворков и обязательного бэкенда.

---

## 🚀 Состав экосистемы

Репозиторий включает в себя 5 взаимосвязанных сервисов, доступных через единую главную страницу-хаб:

### 📄 Документы (`/document`)
* Текстовый редактор для составления отчетов, заметок, статей и документов.
* Минималистичный и сфокусированный на контенте интерфейс.

### 📊 Презентации (`/slides`)
* **Интерактивный плеер слайдов:** Полноэкранный режим показа, навигация, прогресс-бар.
* **ИИ-Помощник:** Генерация структуры презентаций и чат-помощник (интеграция с OpenAI API и Google Apps Script).
* **Заметки докладчика:** Подсказки к каждому слайду в отдельном блоке.
* **Разнообразные макеты:** Титульные слайды, списки, медиа-слайды (картинки/видео), две колонки, цитаты и блоки кода.
* **Мультиязычность:** Встроенная поддержка интерфейса на 6 языках (RU, EN, DE, ES, FR, ZH).

### 📝 Формы и Квизы (`/forms`)
* **Разнообразие типов вопросов:**
  * Одиночный (`radio`) и множественный (`checkbox`) выбор.
  * Выпадающие списки (`select`) и текстовый ввод (`text`) с поддержкой инлайновых полей `[input]`.
  * Интерактивные **Флеш-карты** (`flashcard`) с 3D-анимацией переворота.
  * **Пазлы и сортировка** (`puzzle-drag`) с поддержкой Drag-and-Drop.
  * Информационные слайды с медиафайлами.
* **Панель администратора:** Редактирование, сортировка вопросов, гибкие таймеры, дедлайны и ограничение попыток.
* **Печать форм:** Генерация бланка A4 для проведения бумажного тестирования.

### 📈 Таблицы (`/spreadsheets`)
* Инструмент для структурирования данных, расчётов и работы с табличными значениями.

### 📌 Keeps (`/keeps`)
* Сервис быстрых заметок, списков дел (To-Do) и текстовых фрагментов.
* Удобная организация мыслей и оперативных задач в виде стикеров.

---

## ✨ Ключевые особенности платформы

* **Главный хаб (`index.html`):** Единый портал с кастомными иконками, интерактивными карточками сервисов, плавным анимационным оверлеем загрузки и одноразовым уведомлением о ребрендинге проекта.
* **Полная автономность:** Вся логика выполняется на стороне клиента. Данные сохраняются в `localStorage` браузера.
* **Импорт и экспорт:** Выгрузка и загрузка проектов (презентаций и форм) в формате `.json` для удобного обмена.
* **Современный дизайн:** Поддержка тёмной и светлой тем оформления, системного режима, плавные анимации и кастомные модальные окна (Alert, Prompt, Confirm, API Info).
* **Адаптивность:** Полная поддержка мобильных устройств, планшетов и ПК.
